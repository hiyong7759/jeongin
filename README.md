# 정인 통합건강 상담센터

기존 홈페이지 프로토타입과 제공된 이미지를 기반으로 만든 반응형 정적 웹사이트입니다.

- 사이트: https://hiyong7759.github.io/jeongin/
- 실행: `python3 -m http.server 8000` 후 http://localhost:8000 접속
- 배포: GitHub Pages에서 `main` 브랜치의 `/ (root)`를 게시합니다. `main`에 푸시하면 자동 반영됩니다.
- 별도의 빌드 과정이나 패키지 설치는 필요하지 않습니다.

상단은 로고·바우처 안내·상담 문의로 구성하고, 메인 섹션 탐색은 오른쪽 ‘정인 둘러보기’에 모았습니다. 바우처 안내는 독립 페이지 [voucher.html](voucher.html)에서 제공합니다. 상담 시간, 비용, 연락처 등 미확정 정보와 예약 기능은 안내 준비 중으로 표시합니다. 섹션별 구성 설명도 제공합니다.

공간 사진은 공간 갤러리에만 모았습니다. 자연 비주얼과 대표자 사진 편집 기록은 [VISUALS.md](VISUALS.md)에 있습니다. 스크롤 시 요소별 등장, 미세한 이미지 움직임, 읽기 진행 표시를 적용하며 운영체제의 동작 줄이기 설정에서는 움직임을 비활성화합니다. 기본 앵커·뒤로 가기·직접 링크 동작을 유지합니다. 넓은 PC 화면(1440px 이상)에서는 오른쪽에 전체 목차와 현재 위치를 항상 표시하며, 본문과 겹치지 않도록 별도 여백을 둡니다. 좁은 PC 화면에서는 마우스 호버, 모바일·태블릿에서는 탭, 키보드에서는 Enter/Space로 펼칩니다. 접이식 목차는 선택·바깥 클릭·Escape로 닫힙니다.

본문은 접기·펼치기 없이 12개 섹션으로 이어집니다. 본문 최대 너비는 1,024px이며, 화면별 좌우 여백과 제목·설명 사이 간격을 확보합니다. 일반 섹션은 화면 높이에 고정하지 않고 내용에 맞춰 이어집니다.

상담 방식 4개와 공간 5개는 모든 화면에서 **일반 세로 스크롤만으로** 한 장면씩 좌우 이동합니다. 별도의 가로 스와이프나 화살표 조작을 요구하지 않습니다. 화면보다 긴 장면은 같은 세로 스크롤로 본문 끝을 먼저 읽고 다음 장면으로 이동합니다. 마지막 장면 이후에는 일반 페이지 읽기로 이어지며, 위로 스크롤하면 역순으로 돌아갑니다. 동작 줄이기 설정에서는 장면 전환 애니메이션을 끕니다.

상담 카드에는 핵심 설명을 두고 긴 부연 설명은 캐러셀 바로 아래에 계속 표시합니다. 고민 목록·이력·FAQ·이용안내는 한 열의 읽기 흐름으로 나눠 동시 노출량을 줄였습니다. 목차는 모바일에서 오른쪽 아래에 배치합니다.

원문 대비 복원 내용과 미확정 운영정보는 [CONTENT_REVIEW.md](CONTENT_REVIEW.md)에 정리했습니다.


제목과 일반 본문은 최대 1,024px 정렬을 유지합니다. 상담·공간 캐러셀의 레일은 좌우 여백까지 확장되어 이전·다음 카드 일부가 보이며, 선택한 카드의 시작점은 본문 왼쪽 정렬선에 맞춥니다. 화면 자체에는 가로 스크롤이 생기지 않습니다.


공통 디자인은 `assets/site.css`, 바우처 페이지의 추가 스타일은 `assets/voucher.css`에 있습니다. 바우처 안내는 2026년 9월 25일 공식 자료 기준이며 페이지에 출처를 연결했습니다. 정인의 제공기관 등록·유형은 확인 전까지 미확정으로 표시합니다.
